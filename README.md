#  Indian Stock Market Analyzer

## About the Project

The **Indian Stock Market Analyzer** is a Python project that analyzes the daily performance of selected Indian stocks using live market data from the **Yahoo Finance API (`yfinance`)**.

I built this project to combine my interest in **Economics, Finance, and Data Science** while improving my Python programming skills. Rather than working with sample datasets, I wanted to explore real-world financial data and understand how Python can be used to automate market analysis.

This project retrieves the latest stock prices, calculates daily returns, compares the performance of multiple companies, visualizes the results using charts, and exports the analysis as a CSV report.

Although this is a beginner-level project, it helped me understand how programming can be applied to solve practical problems in finance.

---

# 🎯 Objectives

This project aims to:

- Retrieve live stock prices from Yahoo Finance
- Calculate daily percentage returns
- Compare the performance of multiple companies
- Identify the best and worst performing stocks
- Calculate the average market return
- Visualize stock market data using graphs
- Export the analysis as a CSV report

---

# Features

- Fetches live stock prices using the Yahoo Finance API
- Calculates daily percentage returns
- Identifies the best-performing stock
- Identifies the worst-performing stock
- Calculates the average market return
- Visualizes stock prices using bar charts
- Visualizes daily returns using bar charts
- Exports the complete report as a CSV file
